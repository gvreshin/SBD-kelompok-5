# Our Internship Portfolio

A responsive portfolio website presenting the internship profiles of Nabila Ghaida Sigit, Najwaturrohmah, and Wisnu Hadi Sanicko. Each profile includes education, experience, skills, contact information, and a downloadable CV.

**Live website:** [gvreshin.github.io/SBD-kelompok-5](https://gvreshin.github.io/SBD-kelompok-5/)

## Features

- English and Indonesian language toggle
- Light and dark themes, with the selected theme saved in the browser
- Responsive navigation and layouts for mobile and desktop
- Individual profile pages with CV downloads and contact links

## Run locally

Clone or download this repository, then open `index.html` in a web browser. The site uses plain HTML, CSS, and JavaScript; no build step or package installation is required.

## Project structure

| Path | Purpose |
| --- | --- |
| `index.html` | Home page with links to all profiles |
| `nabila.html`, `najwaturrohmah.html`, `wisnu.html` | Individual profile pages |
| `styles.css`, `theme.css` | Layout, responsive styling, and light/dark color themes |
| `script.js` | Profile content, language toggle, theme toggle, and navigation |
| `assets/` | Downloadable CV documents |

The site is published with GitHub Pages from the `main` branch.
